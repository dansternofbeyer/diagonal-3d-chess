..TRY A NEW MODEL..

How to change a model for good
  1. Open blender/pieces.blend (or run blender/build_pieces.py).
  2. Edit the piece. Keep it centred, about 0.8 wide and 0.9 tall. Use the material “Body” for the main colour and “Trim” for accents.
  3. Export it as models/<name>.glb (or run the script's export).
  4. Run python3 tools/bundle_models.py in the project folder.
  5. Reload this page.
